# DMOL Studio — Vercel Prototype

Static concept site prepared for visual evaluation only.

## Deploy to Vercel
1. Unzip this folder.
2. Create a new GitHub repository and upload all files, **or** drag/import the folder into Vercel using your preferred workflow.
3. In Vercel choose **Other / Static** if asked for a framework. No build command is required.
4. Deploy.

## Pages
- `/` homepage
- `/portfolio`
- `/about`
- `/contact`

## Important
- This prototype uses a small selection of public DMOL Studio imagery copied from the current public website strictly as design-demo material for the requested redesign.
- Replace/confirm production image assets before launch and optimize final images.
- Contact form is intentionally non-functional. Connect it to your preferred service/CRM before production.
- Copy is concept copy based on public DMOL Studio site content and should be approved before production.
